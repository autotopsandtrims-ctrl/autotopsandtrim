# Auto Tops and Trim

Static single-file website for Auto Tops and Trim.

## Structure

index.html is the entire site (HTML, CSS, and images inlined as data URIs).

## Deployment

This repo is connected to Vercel for automatic deployments. Every push to main triggers a new production deployment at autotopsandtrim.com. No build step is required, this is plain static HTML served as-is.

## Updating the site

Replace index.html at the repo root, then commit and push to main using git add, git commit, and git push.
